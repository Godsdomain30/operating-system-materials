# Lab 2.1: C Libraries, Linking, and ELF Executable Structure

## Objective

This lab focuses on understanding how C programs interact with the C Standard Library and how Linux builds and loads executables. I completed tasks covering library locations, static and dynamic linking, and inspecting ELF binary structures using `readelf` and `ldd`.

## Files

* `procinfo.c` – C source code that displays Process ID (PID), Parent Process ID (PPID), and current system time.
* `procinfo.o` – Object file generated during compilation.
* `procinfo` – Standard executable file.
* `procinfo_dynamic` – Dynamically linked executable.
* `procinfo_static` – Statically linked executable.
